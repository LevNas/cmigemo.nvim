# flash ジャンプの挙動

`require("cmigemo.ext.flash").jump()` は [folke/flash.nvim](https://github.com/folke/flash.nvim) の上に、ローマ字入力と日本語ジャンプを両立させるための挙動を実装しています。

## ラベルと入力の非衝突（先読み割当）

ローマ字入力とラベルジャンプは同じ a-z キー空間を使うため、素朴に実装するとどちらかが負けます（入力がラベルに奪われて誤ジャンプする、またはラベルが表示されるのに押しても飛ばない）。

cmigemo.nvim はラベルの**割当前**に、ラベル候補の各文字について「現在のクエリ+その文字」が可視テキストにまだマッチし得るかを検索本体と同一の機構で先読みし、続きになり得る文字をラベルに使いません。これにより：

- **表示されたラベルは押せば必ずジャンプする**
- **クエリの続きとして意味のある文字は必ず入力できる**

が構造的に保証されます。判定が押下時ではなく割当時に行われるため、表示と挙動が乖離しません。

## ラベルの表示

- **1文字目からラベルが表示**されます（`label.min_pattern_length = 1` 既定）。短い ASCII 対象（`if` 等）も2文字でピックできます
- **ラベルはマッチ先頭の1文字左のセルに重畳**されます（`label.before = true` 既定）。マッチした文字列自体は隠れません。行頭マッチは列0へクランプされ、1文字目に重畳します
- いずれも `jump(opts)` の opts で上書きできます

## 複合語への継続入力（compound 分節）

migemo は辞書に読み全体が載っている語しかマッチできないため、確定した語の先へ入力を続ける（`seisanseini` → 生産性**に**、`seisanseikoujou` → 生産性**向上**）ことが本来できません。

cmigemo.nvim は「バッファに実在するマッチ」をオラクルとして入力ローマ字を自動分節し、各分節の migemo パターンを連結して照合します（`(生産性|…)(に|…)`）。分節は打鍵ごとに増分的に解決され、貪欲な誤分節（生産+性向 のような「マッチするが意図と違う」分割）は確定済み分節へのフォールバックで回復します。

かな混在（`zerokara` → ゼロから）や活用語（`hajimeru` → 始める）もこの機構で解決します。

## 読みモード（MeCab）

[MeCab](https://taku910.github.io/mecab/) が PATH にある（または `mecab_cmd` で指定した）環境では、照合が**読みモード**に切り替わります。可視テキストを MeCab で形態素解析して読みインデックスを構築し、入力ローマ字をカタカナへ変換して読みストリームに直接前方一致させます（形態素境界起点・形態素跨ぎ自由）。

バッファ自身の読みが照合の正解になるため、辞書のカバレッジに依存せず、複合語も語境界を越えて確実にマッチします（`kirokusuru` → 記録する のような migemo 辞書では不可能なケースも解決）。

照合は3層のフォールバック構成です：

1. **読み照合** — 形態素境界起点でカタカナ前方一致
2. **リテラル照合** — ASCII 識別子などをそのまま照合（常時併用）
3. **migemo 照合** — 上2層が0件のときのみ。MeCab の誤読・別読み（生物=セイブツ/ナマモノ等）を回収

MeCab が無い環境では従来どおり migemo（+compound 分節）で動作します（機能後退なし）。

### 制約

- 読みマッチの開始位置は**形態素境界のみ**です（読み位置→表層バイト位置の対応が形態素単位でしか取れないため）。語中からの開始が必要なケースは migemo 層が部分的に回収します
- 長音「ー」は母音クエリ文字に緩く一致します（コンピューター等の外来語対応）
- 読みが取れない形態素（記号・数値・未知語）は読みストリームを分断します。ただし**カタカナ表層の未知語は表層をそのまま読みとして合成**するため分断しません（スマートフォン等、ipadic 非収載の外来語対策。同じ語が文脈によって未知語/既知語分割と揺れても、部分ヒットが migemo フォールバックを遮蔽して未知語側だけ落ちる事故を防ぐ）

## 文節ジャンプ

`require("cmigemo.ext.flash").bunsetsu()` は [budoux.lua](https://github.com/atusy/budoux.lua) による文節境界をジャンプ対象として列挙します（クエリ入力なし、`;` / `,` で次/前へ移動、ラベルまたは `<CR>` で確定）。`group_size` で何文節をひとまとまりにするか指定できます（既定: 2）。
